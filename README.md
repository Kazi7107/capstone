# Redline · CSS 496 Capstone Portfolio

Portfolio site for **Redline**, a web app that shows used car buyers in Washington the true 5-year cost of owning a specific car: depreciation, fuel, insurance, maintenance, repairs, and taxes and registration.

**Live site:** https://kazi7107.github.io/capstone/

Kazim Syed · B.S. Applied Computing (Data Analytics minor) · CSS 496 Capstone · University of Washington · Autumn 2026

## Tech

Plain HTML and CSS, no framework or build step, hosted on GitHub Pages from `main` (root). Fonts: Barlow Condensed, IBM Plex Sans and IBM Plex Mono via Google Fonts. All styles live in `style.css`; images go in `images/`.

The Redline app itself is a separate project built with Next.js, Supabase and Vercel.
